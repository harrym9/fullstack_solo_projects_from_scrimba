Blog three: DOM Manipulation & Interactive Menus

Interactive JavaScript challenges on Scrimba pushed me to master DOM manipulation and event listeners. Building my own animated hamburger menu from scratch felt like a huge milestone!

Bridging CSS Transitions and JavaScript

Instead of writing complicated animation logic in JavaScript, I learned how clean it is to toggle an active class with classList.toggle('active') and let CSS transitions handle the smooth off-screen slide and the 45deg icon rotation.

Debugging Tiny Typos

Debugging why my hamburger menu wasn't triggering taught me to inspect class names and CSS units carefully—catching a missing letter in 'active' or using deg instead of % in rotate() are lessons I won't forget!
