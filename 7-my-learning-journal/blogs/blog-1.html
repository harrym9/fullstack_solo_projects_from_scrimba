Blog one: Building a Solid HTML & CSS Foundation

Starting the Scrimba Fullstack Developer Path! Diving back into semantic HTML and modern CSS fundamentals made me realize how much cleaner my layouts can be with a solid foundation.

Why Semantic HTML Matters

When I first started writing HTML, it was tempting to wrap everything in a generic div. Through Scrimba's interactive screencasts, I learned how landmarks like header, nav, main, section, article, and footer make code both easier to read and far more accessible to screen readers.

Refactoring My CSS Mindset

Understanding box-sizing, margin collapsing, and relative units like rem and em saved me from fighting the browser. Instead of hardcoding pixel widths everywhere, I now let content flow naturally and style from the outside in.
