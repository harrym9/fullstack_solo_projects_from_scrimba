# Metric / Imperial Unit Converter

An interactive unit conversion web app that converts a numeric input between Metric and Imperial measurements in both directions.

## Features

- **Length Conversion**: Meters ↔ Feet
- **Volume Conversion**: Liters ↔ Gallons
- **Mass Conversion**: Kilograms ↔ Pounds
- **Formatted Output**: Displays bidirectional results rounded to 3 decimal places.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (`Inter`)

## Getting Started

1. Clone the repository and navigate to this project folder:
   ```bash
   cd 4-unit_converter
   ```
2. Open `index.html` directly in your browser, or run it via a local server (e.g., VS Code Live Server).
