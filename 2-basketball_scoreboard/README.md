# Basketball Scoreboard

An interactive digital basketball scoreboard for tracking **Home** and **Guest** team scores in real time.

## Features

- **Real-Time Score Tracking**: Separate displays for Home and Guest teams.
- **Point Controls**: `+1`, `+2`, and `+3` buttons for each team.
- **Reset Functionality**: `Reset` button to clear both scores back to `0`.
- **Digital Scoreboard Aesthetic**: Uses the `Cursed Timer ULiL` display font for an authentic scoreboard look.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
