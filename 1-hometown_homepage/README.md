# Visit Gebze — Hometown Homepage

A static hometown travel guide webpage showcasing Gebze and the surrounding Kocaeli region near İstanbul, built with semantic HTML and CSS.

## Features

- **Hero Header**: Introduces Gebze with a full-width banner and typography styled with Google Fonts (`Montserrat`).
- **Top 3 Activity Places**: Highlights local attractions—**İzmit Clock Tower**, **Ormanya**, and **Kartepe Cable Car (Teleferik)**—in a card layout.
- **Local Guide Card**: Footer section featuring a personal guide profile card.
- **SEO & Social Meta Tags**: Includes Open Graph and Twitter Card metadata in `index.html`.

## Tech Stack

- HTML5
- CSS3
- Google Fonts (`Montserrat`)
