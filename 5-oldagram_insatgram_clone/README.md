# Oldagram — Instagram Clone

A classic-art-themed Instagram feed clone featuring posts from historical painters—Vincent van Gogh, Gustave Courbet, and Joseph Ducreux.

## Features

- **Dynamic Post Feed**: Renders posts from JavaScript data (`posts` array in `script.js`), including user avatars, locations, post images, likes, and captions.
- **Double-Click to Like**: Double-clicking any post image toggles its liked state and updates the like counter and heart icon.
- **Instagram-Inspired Layout**: Includes header branding, action icons (like, comment, DM), and `Source Sans 3` typography.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (`Source Sans 3`)

1. Clone the repository and navigate to this project folder:
   ```bash
   cd 5-oldagram_insatgram_clone
   ```
2. Open `index.html` directly in your browser, or serve it with a local development server (e.g., VS Code Live Server).
