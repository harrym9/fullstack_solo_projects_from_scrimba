# Random Password Generator

A simple, fast web tool that generates two strong, random 15-character passwords with a single click.

## Features

- **One-Click Generation**: Generates two independent 15-character passwords simultaneously.
- **Full Character Set**: Combines uppercase letters, lowercase letters, numbers, and special symbols.
- **Clean UI**: Styled with Google Fonts (`Karla`) and clear output fields for easy copying.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

1. Clone the repository and navigate to this project folder:
   ```bash
   cd 3-password_generator
   ```
