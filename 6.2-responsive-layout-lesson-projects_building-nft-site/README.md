# Wildly Expensive JPEGs — Responsive NFT Site

A responsive landing page ("FoolsGold.com") built to practice mobile-first and responsive CSS layout techniques.

## Features

- **Responsive Breakpoints**: Adapts layout, navigation, and image containers across mobile (`max-width: 767px`) and tablet/desktop (`min-width: 768px`) viewports.
- **Flexbox Layout**: Uses Flexbox for the header navigation and side-by-side feature cards on larger screens.
- **Semantic Structure**: Organized into header navigation, hero product showcase, two-column feature section, and footer.

## Tech Stack

- HTML5
- CSS3 (Media Queries & Flexbox)
- Google Fonts (`Roboto`)
